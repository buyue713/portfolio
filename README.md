# 卜越 · 作品集 2026.11

## 文件
| 文件 | 用途 |
|---|---|
| `index.html` | 网页版作品集，单文件、零依赖（不引第三方脚本与字体），双击即可打开 |
| `卜越_作品集_2026.pdf` | A4 三页版，投递页面「附件」一栏直接上传这份 |
| `_shots/` | 渲染验收截图（390 / 768 / 1440 三档屏宽、暗色版、PDF 逐页） |

## 结构
1. hero：一句话主张 + 三个数字（83,371 / 4,568 / 2,721）
2. 六个项目，按「与本岗位适配度 + 工程量」从大到小排；每个都写「做了什么 / 怎么做 / 有什么意义」，右侧给关键数字与标签
3. 附录：2,721 行网关（工程底子）
4. 方法四步：取数 → 对账 → 成稿 → 归档
5. 联系：邮箱、电话、到岗口径

## 设计口径（ui-design skill）
- 字阶 6 档：12 / 14 / 17 / 21 / 40 / 56 px
- 圆角 3 档：0 / 28 / 980 px
- 零投影、发丝线分隔、毛玻璃胶囊导航
- 背景 5 种：白 / #f5f5f7 / #000 / 暗态 #0b0b0c / 卡片 #1d1d1f
- 饱和色只出现 1 次（联系区 CTA 按钮）
- 三档屏宽均无横向溢出（390 / 768 / 1440）

## 改字位置
- 正文：`index.html` 里 `<article class="mod">` 的各 `.row p`
- 数字：`.big` 与 `.sidecap`
- 打印样式：`@media print` 段（A4、13mm 边距、卡片不跨页）

## 验收命令
```bash
NODE=.../node
$NODE ../../tools/webcdp.mjs --url "file:///C:/求职/output/作品集/index.html" \
  --widths 390,768,1440 --shots _shots --scheme light --pdf 卜越_作品集_2026.pdf
```
（启动无头 Edge 需要完整进程权限；默认沙箱下会挂住。）
